# 胶囊视觉改为异形卡堆

Status: accepted（2026-11-17 设计讨论达成共识并实现。四方案原型对比后由用户选定；取代 0002 中「关闭态外观」「浮层分页」「建胶囊预览」的视觉决策，容器定位与全部交互决策继续有效）

## 背景

0002 把胶囊关闭态定为「真卡等比缩小进固定 3×3 九宫格」，实测这组几何撑不住：

- 面板 352px、内边距 16px、格距 12px，每格只有 ≈99×83px；真卡按 `fit ≈ 0.425` 等比缩小后，标题 13px 缩成 5.5px、页脚 11.5px 缩成 4.9px，低于任何可读下限（「过小」）。
- 格子锁死 232:196，而卡片高度不定（图片比例、正文长度都不同）：高卡被拦腰裁断、矮卡底部留白，九个格子裁切线各不相同（「变形」）。
- 浮层里同一机制（fit ≈ 0.868）标题也只有 ~11px。
- 玻璃面板叠玻璃迷你卡，与项目已建立的纸面、衬线、邮票母题相悖（「美学不符」）。

结论：只要格子里塞的是「整张真卡等比缩小」，过小与变形无解——固定比例的格子装不下高度不定的卡片。

用四方案原型（现状 / 封面格 / 邮票版张 / 异形卡堆）对比后，用户选定异形卡堆：卡片按格子宽度**原字号重排**而非缩放，形状随成员数自适应。

## 决策

| 事项 | 决策 |
| --- | --- |
| 关闭态外观 | 两列瀑布流「卡堆」：白纸面板宽 352px、内边距 12px、列距 10px。成员卡按列宽重排，字体、行距、页脚保持原字号，不缩放；媒体压到 112px 等高，正文压到 3 行，保证行数可控。卡片 ±0.5° 轻微错落，像手放在桌上的纸。 |
| 关闭态容量 | 最多露 4 张（按 `itemIds` 顺序），放不下的成员折成面板底部的纸堆边缘（两道错位纸边），不画空槽位、不显示条数。 |
| 关闭态交互 | 不变（0002）：点卡堆任意位置开浮层；右键「整体成稿 / 解散胶囊」；拖卡换归属或移出。 |
| 浮层 | 同一卡堆放大居中：白纸面板 `min(560px, 可用宽)`，两列瀑布流，一页 6 张；窗口高度受限时压缩媒体高度（≤660px 时 120px、≤600px 时 100px）代替旧方案的收窄宽度。 |
| 浮层交互 | 全部不变（0002）：顶部居中改名、卡片拖动排序、边缘停顿跨页、右键「移出胶囊 / 整体成稿 / 解散胶囊」、拖到模糊背景移出、Esc 或点背景关闭、键盘左右翻页。 |
| 建胶囊预览 | 从九宫格玻璃预览改为卡堆形状的白纸预览：2×2 圆角空格 + 一道纸堆边，铺开/收起动画不变。 |
| 稀疏胶囊 | 成员少时卡堆自然变矮（2 成员 ≈230px，4+ 成员 ≈450px），资料架底缘参差是本方案的已知取舍，接受。 |

## 验收场景

1. 9 成员胶囊：关闭态显示 4 张原字号卡（标题 13px 可读）+ 纸堆边缘，无空槽位；名字在面板下方。
2. 2 成员胶囊：两卡并排填满，无空白。
3. 点卡堆任意位置：浮层一页 6 张两列瀑布流；13 成员共 3 页，左右圆钮翻页，键盘方向键可用。
4. 浮层拖动排序、拖到模糊背景移出、右键解散——行为与 0002 一致。
5. 拖卡片悬到卡堆上：面板出现描边放大提示，松手收进。
6. 标签筛选：只显示含命中成员的胶囊，命中成员按顺序进卡堆，超过 4 张折叠。
7. 多选（Shift/Ctrl+点）：可选中胶囊进统一成稿入口，选中态有描边。

## 后果

- 删除 `CapsuleCell` 的 transform 缩放与 `ResizeObserver` 测量，卡片渲染回归普通 DOM；`CAPSULE_SIZE`、九宫格样式与空槽位一并下线。
- 资料架高度参差、关闭态最多可见 4 名成员、浮层从 9/页改 6/页——均为本方案主动取舍。
- 「大文件夹」的透明玻璃材质让位给白纸卡堆，与首屏邮票条、衬线首字、tone 色纸共用一套母题。

## 代码影响

- `client/capsule.jsx`：`PILE_SLOTS = 4`、`PER_PAGE = 6`；`CapsuleCard` 改渲染两列卡堆 + 纸堆边缘；`CapsulePreview` 改卡堆形状；`CapsuleView` 改一页六张瀑布流；删除 `CapsuleCell` 与 `CAPSULE_SIZE`。
- `client/styles.css`：`.md-capsule-*` 九宫格/玻璃面板样式替换为 `.md-pile` 系列；浮层改白纸面板；资料架 `align-items: flex-start`。
- `client/canvas.jsx`：无需改动（成员拖出沿用同一 `data-capsule-item` 挂点）。

## 回滚

按提交回退 `client/capsule.jsx` 与 `client/styles.css` 即可恢复九宫格；四方案对比原型保留在 `prototype/capsule-redesign.html`（抛弃式，不随发布打包）。
