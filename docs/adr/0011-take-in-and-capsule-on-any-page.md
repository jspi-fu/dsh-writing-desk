# 收下与胶囊下放到任意页面:粘贴/拖入建灵感,排期页也能操作胶囊

Status: accepted(2026-11-19 与用户逐项定案;实现随本 ADR 落地。**「胶囊成员逐个同步排期/状态/发布」被 0013 的「排期以素材主体为单位、状态属于作品」取代;胶囊折叠、拖拽、收下与卡到卡规则继续有效。**)

## 背景

用户（2026-11-19）：胶囊界面做得不错但不够方便——① 复制了文件（PDF、图片等）应能直接粘贴进灵感、排期等任何允许创建灵感卡片的地方；② 资源管理器里打开文件也应能拖拽创建；③ 胶囊目前只在灵感界面出现，需要在任意界面都能操作胶囊并且「同步」。

「同步」经确认指的是同一份数据在各处一致，不涉及多设备或多窗口。原设想是把胶囊做成宿主级的右下角气泡加 `Ctrl+Shift+V` 快捷键，用户否决：本插件是纯侧边栏插件，不做快捷键，也不许往宿主框架层塞浮层；「任意界面」限定为工作台内所有显示灵感卡的页面。

排期页（`client/schedule.jsx`）的待排期托盘把胶囊成员逐条列出，与灵感墙「成员不单独出现」（`client/wall.jsx:315`）不一致，因此拖卡到卡合成在托盘里根本看不见。这是本次必须先折叠的理由。

## 决策

| 事项 | 决策 |
| --- | --- |
| 收下（粘贴） | 工作台内任意处按浏览器原生 `Ctrl+V` 即收下：文件落成文件类灵感（标题取文件名去扩展名），位图落成图片灵感（标题 `粘贴的截图 HH:MM`，同一分钟加序号），文字落成笔记，单个 URL 落成链接卡（先 `preview-url` 补标题/简介/封面，失败退回 URL 本身）。不弹编辑界面。 |
| 收下（拖入） | 从资源管理器拖入文件走同一条收下路径；整窗描一条「放下即收下」的边，日历日格与胶囊浮层各自叠领域高亮。拖到胶囊卡或胶囊浮层上＝成为该胶囊成员；拖到其他卡片上等同空白处（只新建，不合成）。 |
| 焦点让路 | 焦点在 input/textarea/contenteditable 且剪贴板有文字时让给输入框；剪贴板只有文件或位图时照常收下。 |
| 落点 | 落点决定去向：拖到日历某天＝排那天（09:00）；拖进胶囊浮层或胶囊卡上＝成为该胶囊成员；拖到灵感墙另一张灵感卡上＝合成胶囊；拖到对话输入卡（含接驳条）＝添加到当前会话；其他落点（灵感墙空白、排期页托盘空白、内容页等）＝新建在灵感墙。拖出胶囊浮层仍是移出。 |
| 去重 | 文件名 + 字节数 + lastModified 三项全对才算重复；命中不新建、不跳转，只提示「这个已经在灵感里了」。判定在浏览器本地做（`writing-desk-taken`），因为墙面数据不存字节数与修改时间。 |
| 撤销 | 一批收下算一次可撤销记录，toast 报「收下 N 个灵感」并带撤销。 |
| 上限 | 前端不再限制文件个数与合计体积（对话框与粘贴一致），单个文件按宿主 `MAX_UPLOAD`（250MB）；逐个上传，一个失败不中断其余，最后报失败数。 |
| 排期页托盘 | 胶囊成员在托盘里折叠成一张胶囊卡，与灵感墙一致；只要胶囊里还有成员待排期（未排期、未发布）这张卡就出现。入口口径抽到 `src/state.js` 的 `awaitingSchedule(item)`，排期页与托盘共用。 |
| 托盘分组 | 胶囊卡按整张卡算成稿（`capsuleDrafted(members)`＝任一成员成稿即整张成稿）：成稿进「已成稿」组，否则进「灵感」组；不设第三组。 |
| 托盘拖卡 | 卡拖到卡＝合成胶囊：灵感→灵感新建胶囊（名字取目标卡标题）、灵感→胶囊加入该胶囊、胶囊→灵感把那张收进该胶囊、胶囊→胶囊两胶囊合并（保留目标名）。沿用 `src/ops.js` 的 `detachFromOtherCapsules` 保证一个灵感只属于一个胶囊。 |
| 胶囊卡到日历 | 拖胶囊卡到日历某天＝整张胶囊一起排到那天（09:00），已经排期的成员也一起挪过来——胶囊是一张卡，不摊在两个日子上；日历上整张胶囊也只露一个签（成员不散成几条），拖回托盘即整张胶囊撤排期；成员不再能从托盘单条拖到日历（要单排先开浮层移出）。 |
| 胶囊整体状态 | 胶囊是一张卡：`schedule_item` / `set_status` / `publish_item` / `update_item` 改到某个成员时，同一胶囊的全部成员一起改，回执报胶囊名（`kind: 'capsule'`），回执词条在 `src/en.js`。会话写回只落在胶囊的第一个成员（成稿输入的既有约定：`targetId` 取第一个来源），其余成员状态用 `syncCapsuleStatus` 对齐；不把成稿正文复制到每个成员——胶囊共享状态，不复制产出。 |
| 示例数据 | 示例条目一律从「灵感 / 待排期」开始，不再自带排期与已发布（示例只示范长什么样）。存量状态文件靠 `migrateState` 里的一次性重置退回「灵感 / 待排期」：只动 `sample: true` 且还没写成稿的条目，标记 `sampleScheduleReset` 落库，之后用户的排期不会被反复清掉；自建条目与已写成稿的示例不动。 |
| 墙面卡到卡 | 灵感卡拖到另一张灵感卡上＝合成胶囊，走的还是「多选后点合成胶囊」那条 `add_capsule`（与托盘内卡到卡同一套规则）。拖到自己身上不算。 |
| 添加到当前会话 | 灵感卡与胶囊卡都能拖到对话输入卡：落点是整块输入卡而不只是 36px 的接驳条；HTML5 落手由接驳条在 `window` 捕获阶段接管（输入框自己不会 `preventDefault`，不接管就收不到 drop）。胶囊用 `text/writing-desk-capsule` 单独成条，不混进灵感 ID。落手复用「添加到当前会话」按钮同一条 `addReferenceToCurrentSession`：引用签由宿主草稿逐条插进去，接驳条自己不再画签条、也不再整段替换草稿。 |
| 胶囊浮层 | 删掉头部「关闭」X（点遮罩空白处与 Esc 已经能关）；不加「移出」按钮（拖出即移出）。 |
| 内容页 | 本次不动：内容页之后会大改、定位不同。 |

## 不做

- 不做快捷键、不做宿主级胶囊气泡，不往 `shell.overlay` 之类框架层挂件。
- 不在内容页做胶囊感知（胶囊徽标等方案随内容页推迟）。
- 不做多设备/多窗口同步，不做后台轮询。
- 不设前端上传数量/体积上限（只保留宿主单文件上限）。

## 交互流程

1. 复制文件后在任意工作台页面 `Ctrl+V`：卡片直接出现在灵感墙，toast 报数并可撤销；在排期页时落进待排期托盘的「灵感」组。
2. 从资源管理器把 PDF 拖到日历某天：松开即建文件灵感并排到那天的 09:00。
3. 把图片拖进打开的胶囊浮层：图片成为成员，浮层页数随之增加。
4. 在待排期托盘把一张灵感卡拖到另一张上：两张合成胶囊，胶囊卡随即折叠出现。
5. 在托盘把胶囊卡拖到日历某天：整张胶囊一起排到那天，已经排期的成员也一起挪过去。
6. 把重复的文件再拖一次：不新建，提示「这个已经在灵感里了」。
7. 在灵感墙把一张灵感卡拖到另一张上：两张合成胶囊，目标卡先亮起描边再折叠成胶囊卡。
8. 把灵感卡或胶囊卡拖到对话输入卡（输入框任何位置，不必对准接驳条）：松开后引用写进草稿，与「添加到当前会话」按钮同一条路径。
9. 在同一张胶囊的任意成员上改状态、排期或发布：其余成员跟着改，回执报胶囊名字。
10. 全新安装：示例数据全在待排期托盘里、都算灵感，没有一条已排期或已发布。

## 验收场景

1. 粘贴位图/文件/文字/URL 四种输入都能在工作台内建出对应类型的灵感；焦点在对话框输入框时粘贴文字不被拦截。
2. 拖文件进日历日格、胶囊浮层、胶囊卡、托盘空白处，分别得到「排到那天」「成为成员」「成为成员」「新建在墙」。
3. 对话框文件页签可拖入文件、可选任意多个，逐个填标题说明；单个超 250MB 时只报这一条的错。
4. 托盘里胶囊成员不单独出现；胶囊卡点开即浮层；只要还有成员待排期胶囊卡就在托盘里，待排期成员全部成稿时进「已成稿」组。
5. 托盘内四种卡到卡组合都能建立正确的胶囊成员关系，且可一次撤销。
6. 灵感墙里灵感卡拖到灵感卡能合成胶囊；灵感卡与胶囊卡都能拖到对话输入卡并写进草稿。
7. `npm test` 全绿；构建后侧栏工作台照常挂载。

## 后果

- 新增 `client/take-in.js`（收下与去重注册表）；`client/index.jsx` 挂窗口级粘贴/拖入并改文件页签；`client/schedule.jsx` 折叠胶囊卡、加卡到卡合成与胶囊到日历；`client/capsule.jsx` 去 X、接文件拖入、胶囊卡可拖；`client/wall.jsx` 灵感卡到卡合成胶囊；`client/card.jsx` 拖起时通知接驳条；`client/dock.jsx` 把落点放大到输入卡并在 `window` 捕获阶段接管落手、胶囊单独成条；`client/styles.css`、`client/en/core.js`、`GLOSSARY.md` 同步。
- `src/ops.js` 的 `add_item` 增加可选 `capsuleId`：新灵感直接落进胶囊，整批收下仍是一次撤销记录。
- 排期页与灵感墙对「胶囊成员不单独出现」取得同一口径；内容页保持原样，等它改版时再对齐。
