# 灵感墙换成货架:参考 StashDock 的卡、弹层、胶囊集合与标签上拉栏

Status: accepted(2026-11-18 与用户逐项定案;实现随本 ADR 落地。**内容页的四列稿子看板被 0015 取代为「我的作品」画廊 + 流程切换;灵感墙与卡片规范继续有效。**)

## 背景

灵感墙是插件的门面,原来的形状是「书桌 + 邮票/卡堆」:236px 多列瀑布流、顶部一句 hero 输入、右键菜单分流成稿入口、类型 chips 与标签 chips 在底部 dockbar 一字排开、胶囊是异形卡堆。用户拿出 StashDock(D:\源自C盘\桌面\StashDock,DSH 货架插件)的整屏截图作为参照,认为它的卡片、导入、筛选打磨得更好,要求**从导入到交互、UI 彻底对齐**,只保留两处刻意不同。

设计分两步完成:先出 A(两层世界)/B(全量参考)/C(同骨异构)三方向对比页(`.impeccable/choices.png`),用户选 **C**——骨架、密度、交互全部照参考,只有稿面/校样这类"纸"保留衬线标题与四色状态点;随后逐项确认顶部入口、缩略图时间轴、分类集合、标签栏形态、删除位置、胶囊语义(见 `.impeccable/wall-decisions.md`)。

## 决策

| 事项 | 决策 |
| --- | --- |
| 墙面语言 | 卡片 = 16:9 封面(顶部裁切、内圆角)+ 1px 内描边 + 两行标题 + 站点行 + 黑胶囊按钮;卡 padding 8px、圆角 26px;悬停 −2px、封面 scale(1.015);墙 `auto-fill minmax(232px, 1fr)`、gap 16、上限 1500。整墙单一网格,不再用多列瀑布流。 |
| 灵感卡片 | 卡上两枚浮钮:左上圆形勾选(多选)、右上垃圾桶(删除,可撤销);只在 hover/聚焦/选中显形 160ms。整卡点击 = **打开编辑弹层**(参考点卡什么都不做,这是第一处刻意不同);Enter/Space 同。卡底黑胶囊分体:主键「创作」直接进创作会话,右侧小箭头展开「添加到对话 / 编辑灵感 / 删除灵感」。**没有星标**(参考有,这是第二处刻意不同)。 |
| 新建入口 | 底部右下圆钮「+」直接打开统一弹层(默认笔记页签);**删除原右键菜单**(引用到对话/去创作会话两条全体退场),成稿入口收进卡片胶囊与多选浮条。 |
| 统一弹层 | 新增与编辑用同一个 `CaptureDialog`:页签 笔记 / 链接 / 文件,页签只在新建时出现;字段 标题 → 想法 → 来源 / 标签 → 来源类型(我写的 / AI 生成的)。编辑态没有任何引用、添加、成稿类按钮,只在左下落一个红色「删除这条灵感」。对话框 520px、34px 圆角,不占满屏,与参考的导入弹层同形。 |
| 链接预读 | 新建链接页签粘贴 URL 后 650ms 防抖,host 新增只读路由 `preview-url`(复用 `harvest`,只回 标题/简介/封面/站点名,**不落库**);只补空字段,用户改过的字段不覆盖。封面以 16:9 预览条露出来。 |
| 重复链接 | 命中已有 URL 时先不提交,弹出「这个链接已经收过。」+ 原标题/URL,两个动作:保留原有(放弃新建)/替换链接(update_item 覆盖标题、正文、URL、来源、标签、来源类型)。 |
| 分类 | 底部保留分段 chips:全部 / 笔记 / 文件 / 链接(原 image/video → 文件,web → 链接,note → 笔记;**金句类型直接删除**,旧 quote 数据按笔记渲染、不删内容)。分类与标签筛选叠加(AND),分类不看会话状态而变化。 |
| 标签上拉栏 | 标签不再在 dockbar 一字排开:底部「标签」按钮拉起抽屉(`TagSheet`),手机键盘式圆角上吸;**竖排单选列表**(每行 40px:标签名 + 右端使用次数,选中行描一个勾),不是一行 chips,标签多时靠滚动也不难找。首项「全部标签」+ 灵感总数,空态一行提示。抽屉高 max 58%。 |
| 搜索与排序 | 顶部第一行 = 搜索框(占位「搜索灵感」,空格分词 AND,140ms 会话内过滤)+ 右侧排序方钮(最近添加 / 最早添加 / 按标题;`wallSort` 进 desk store,跨重开保持)。原 hero 口号、日期、Streak 段落整段撤除。 |
| 时间轴 | 缩略图一行保留,只分「本周」与「之后」两段,中间一条 2×18px 墨色短竖杠 + 竖排「本周」;可左右滑,端点侧渐隐消失,悬停出箭头(触摸不显示、端点变灰禁用、指针在箭头上时不突然消失),键盘左右键把焦点项滚到正中;格子上 hover 出右上「+」= 进创作,点本体 = 打开编辑弹层或胶囊浮层;行末只一个纯数字(胶囊成员不重复计)。 |
| 胶囊 | 胶囊变成**灵感集合卡**:2×2 成员封面 + 左下「N 张」徽标 + footer「胶囊」+ 黑胶囊按钮,同样可勾选、可 hover 解散;没有编辑入口(名字在合成时一次给定)。多选浮条支持「合成胶囊」(仅在 ≥2 个未入胶囊的灵感时出现)。浮层保留一页六格、两侧翻页、拖拽排序、拖出即移出,头部改为静态名字 + 张数 + 添加灵感 + 解散 + 关闭。 |
| 多选 | 封面勾选圆钮直接切换,不要求 Shift/Ctrl;浮条 = 已选 N 项 / 全选 / 添加到对话 / 进入创作 / 合成胶囊(仅 ≥2 个未入胶囊的灵感)/ 删除或解散(选了胶囊时文案变「解散」)/ 取消。删除对胶囊即为解散。 |
| 视觉 | 圆角走参考的三档:卡 26 / 卡片内封面 18 / 弹层 34;ease `cubic-bezier(.22,1,.36,1)`;纸张仍为实心白,玻璃只做 chrome;标题用无衬线,纸面(稿面/校样)保留衬线。 |
| 语义延续 | 灵感/胶囊/成稿输入/创作会话/写回等概念不变;编辑仍不承载成稿入口,成稿只从卡胶囊、多选浮条与浮层进会话。 |

## 不做

- 不做星标、收藏夹、置顶。
- 不做右键菜单(卡片、缩略图、胶囊一律改走卡内浮钮、胶囊/省略菜单与浮层按钮)。
- 不做拖拽导入(文件页签仍走选择器)、不做封面在编辑态替换(重收一次即可)。
- 不做标签重命名/移除(参考在标签项右键里,本期不做)、不做标签多选。
- 不做服务端分页/搜索/排序:墙是本地状态,数据量在千条以内。

## 交互流程

1. 点右下「+」→ 统一弹层(默认笔记)→ 写一句话保存,卡出现在墙面与时间轴。
2. 链接页签粘贴 URL → 自动预读标题/简介/封面 → 补空字段 → 保存;重复则选「保留原有 / 替换链接」。
3. 点卡任意处 = 编辑弹层,改标题/想法/来源/标签/来源类型,保存;左下删除可撤销。
4. 卡底「创作」直接进创作会话;小箭头「添加到对话」把引用塞进当前草稿。
5. 勾选两张以上灵感/胶囊 → 浮条合成胶囊或一起进创作;勾选胶囊可解散。
6. 搜索框过滤、排序方钮换序、「标签」拉起抽屉单选标签;分类 chips 直接切。

## 验收场景

1. 新建(笔记/链接/文件)与编辑打开的是同一个对话框;编辑态无页签、无引用按钮,删除在左下。
2. 粘贴链接 650ms 后标题/简介/站点名/封面自动补全;已填字段不被覆盖;重复链接出现冲突条且保存禁用。
3. 卡 hover 显形勾选与删除;点卡开编辑;Enter/Space 同;点黑胶囊进创作会话说「创作」,箭头菜单三项可用。
4. 胶囊卡显示 2×2 封面与张数,勾选后可解散;浮层内可拖拽排序、拖出移出、添加成员、解散。
5. 标签抽屉从底部拉起、单选、计数正确;搜索与排序作用于卡片与时间轴;行末计数不重复计胶囊成员。
6. 分类 全部/笔记/文件/链接 与标签叠加过滤;旧 quote 数据按笔记正常渲染。
7. `npm test` 全绿;无 JSX 文件漏 `import React`(classic 运行时)。

## 修订（第三批）

- **时间轴两段。** 原先按周分四段（本周 / 上周 / 两周前 / 日期），信息过碎；改为只分「本周」与「之后」，中间 2×18px 墨色短竖杠 + 竖排「本周」，两端各留 12px 渐隐提示，悬停浮现箭头（端点侧变灰禁用、指针停在箭头上时不消失、触摸设备不显示），键盘左右键把焦点缩略图滚到正中。按标题排序时两段不再成立，退化为不分组的一条。
- **计数只留总数。** 行末不再写「N 个灵感 · M 个胶囊」，只一个纯数字；胶囊成员仍不重复计。
- **三种选择方式并存。** ①点左上勾选钮多选（沿用，浮条动作不变）；②在墙面空白处拖出框选矩形，与矩形相交的卡即选中，Shift 追加、松手未拖动则清空；③拖拽卡（选中多个时拖整叠）到胶囊卡上松手即并入，胶囊浮层里拖出即移出——两条都落回既有的 `update_capsule` 白名单，服务端仍会从别的胶囊里自动摘出、成员不足 2 自动解散。
- **浮窗锚定触发按钮。** ⋯ / caret / 排序钮的菜单不再按鼠标坐标定位，改为锚定按钮：正下方 6px、右缘对齐，下方空间不足翻到上方，左右夹取 8px；遮挡问题由此消失（`client/ui.jsx` 的 `openMenuAt`）。
- 证据:`client/wall.jsx`(railGroups / ThumbRail / 框选)、`client/card.jsx`(dragIds)、`client/capsule.jsx`(dropIn)、`client/ui.jsx`(anchor)、`client/styles.css`(.md-railstage/.md-railfade/.md-rail-arrow/.md-railsplit/.md-marquee/.md-tile.is-drop)。

## 修订（第六批：创作入口改用引用签）

本 ADR 正文前部的决策表是初版记录；第三至六批修订依次覆盖了卡片菜单、统一弹层字段、标签锚定小列、多选动作与创作入口，**以修订为准**（旧「不做标签重命名 / 编辑态换封面 / 添加到对话」等表述已过时）。

- **创作不再以纯文本 prompt 开新会话。** 宿主 `conversation.input.dock` 可用时，点卡 / 胶囊 / 多选浮条的「创作」先暂存 `quotePayload`，用 `startSession(undefined, { agentPreset: 'writing' })` 开新会话，由新会话挂载的 dock 把素材以 `insertQuote` **引用签**写进**空草稿**；不自动发送，等用户补一句意图再回车。1.2s 内没有新输入框（宿主复用当前写作会话）则把签补进当前 composer；pending 只消费一次。
- **两种入口同款渲染。** 「添加到当前会话」与「创作」共用 `quotePayload`：灵感 = 标签「灵感」+ 标题 + 来源/摘要，胶囊 = 标签「胶囊」+ 名字 + 张数。宿主没有 `insertQuote` 时，创作仍回退到旧的纯文本 `prompt` + `whenDraftExists: 'append'`。
- **dock 槽位兼容（2026-11-24 修订，覆盖本节原决定）。** 宿主当前 slot 名是 `conversation.input.dock`（session scope，standardProps 含 `inputActions`），旧名 `conversation.composer.dock` 当前版本仍存在但不再注册。> _Contradicts 本 ADR 原决定「两处都尝试注册、各自 try/catch」，但值得重开：两槽并存时会产生两个 `DockRail`，争抢 `client/session-link.js` 的 `composer`/`dockRect` 单例，后挂载实例覆盖前者；各自的 try/catch 还会静默吞掉注册失败。现在只注册 `conversation.input.dock`，删除旧名循环与 try/catch，函数由 `mountComposerDock` 更名为 `mountInputDock`。_
- 证据：`client/session-link.js`（quotePayload / pushQuotes / pendingCreate / claimPendingReference / hasPendingReference）、`client/dock.jsx`（挂载即 claim，失败按 120ms 退避重试 5 次；样式自带 `dock.css`）、`client/index.jsx`（`mountInputDock` 单槽位注册）。沙箱实机截图 `chip-verify.png`：创作会话 hero 显示「创作」，输入框只有一枚引用签，草稿未发送。
