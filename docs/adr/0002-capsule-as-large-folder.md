# 胶囊改为「大文件夹」容器

Status: accepted（2026-11-17 设计讨论达成共识并实现；同日撤销散落模式，见 0003，本文已按只剩灵感流的样子写过。同日的 0004 取代了本文的「关闭态外观」「浮层分页」「建胶囊预览」视觉决策——胶囊现为异形卡堆；容器定位与交互决策继续有效）

## 背景

原来的胶囊是一张浮在成员质心的封面卡：三张封面横排，成员灵感仍散落在画布上，点击只打开改名与成员列表的对话框。它看起来不像华为手机的大文件夹，同一批灵感在画布上出现两次；拖拽也只支持「卡片拖到卡片建胶囊」和「卡片拖到胶囊加成员」，胶囊自身不能拖、成员不能拖出、顺序不能调整。

用户希望胶囊是透明的系统大文件夹：能清楚看到内部的灵感卡片，点开进入一个带分页的居中浮层继续操作。

## 决策

| 事项 | 决策 |
| --- | --- |
| 胶囊的定位 | 胶囊是灵感流顶部的**容器**。成员灵感归入胶囊后不再作为独立卡片出现在灵感流里；成员仍是独立灵感实体，解散或拖出后回到灵感流。 |
| 成员归属 | 一个灵感同一时间只属于一个胶囊。把成员移入另一个胶囊视为「移动」，从原胶囊移除；原胶囊成员少于两个时按自动解散处理。 |
| 最小成员数 | 胶囊至少要有两个成员。任何路径使成员只剩一个（拖出、删除灵感、移入其他胶囊）时，胶囊自动解散，不需要额外确认。 |
| 关闭态外观 | 轻磨砂玻璃的圆角方形面板，宽度固定 352px，面板内边距 16px、格间距 12px；名字在面板下方，**不显示成员数量**。始终是 3 列 × 3 行的九宫格，不随成员数量变形。每格放的就是灵感流里那张卡本身，按同一比例缩进格子：图片压成等高的一条带子，标题、来源与状态照旧，字体和排版跟卡片一致；卡片比格子高时按缩略图裁掉下半截。没有卡的位置直接留白，不画槽位，和面板背景连成一片。 |
| 关闭态交互 | 点面板任意位置（含迷你卡）打开胶囊浮层；右键弹出「整体成稿 / 解散胶囊」；拖迷你卡到别的胶囊上换归属，拖到空白处即移出胶囊。 |
| 胶囊浮层 | 居中的浮层，不在原卡片位置展开，也不跳到独立页面。背后灵感流做模糊处理，面板仍可读。宽度 min(680px, 浮层可用宽)，按窗口高度收窄（660px / 600px 两档）。 |
| 浮层分页 | 同一个九宫格放大成一页九格（3 列 × 3 行 = 9 张）；超过一页时只在面板左右两侧各放一个翻页圆钮，第一页/最后一页自然禁用，页数写在标题下方的说明行里。支持键盘左右方向键翻页（输入框聚焦时除外）。 |
| 浮层操作 | 顶部居中的标题可直接改名（失焦、回车、关闭三个出口都落库）；卡片可拖动排序，拖到面板左右边缘停一下可跨页；右键菜单承担「移出胶囊 / 整体成稿 / 解散胶囊」；浮层上没有其它按钮，Esc 或点背景关闭；点成员卡先关浮层再进编辑界面。 |
| 浮层拖出 | 从浮层把成员卡拖到模糊背景并松手，视为移出胶囊：浮层保持打开，成员回到灵感流。若移出后只剩一个成员，胶囊同时自动解散，浮层随之关闭。 |
| 新建胶囊 | 卡片拖到另一张卡片上，不弹任何命名提示。两卡重叠达到阈值时，一个胶囊形状的玻璃面板从目标卡位置慢慢铺开；此时松手成胶囊，移开则收起取消。默认名取第一条成员的标题（先取第一句，再截到 18 字），没有标题就用正文开头，两样都没有才叫「新胶囊」；之后可在浮层里改名。 |
| 建胶囊阈值 | 拖动卡与目标卡重叠面积达到拖动卡的 30% 并保持 120ms 才铺开；回落到 15% 以下收起（迟滞防抖）。 |
| 拖入已有胶囊 | 卡片拖到已有胶囊上时，胶囊轻微展开提示，松手加入。 |
| 胶囊排序 | 浮层内拖动卡片调整 `itemIds` 顺序；顺序决定关闭态前 9 个与浮层分页顺序。 |
| 解散后的落点 | 不解散之外没有落点：成员本来就是灵感流的一部分，解散只是解除归属，卡片回到原来的时间位置。 |
| 筛选与相关推荐 | 标签/类型筛选时，胶囊只显示命中的成员，只显示含命中成员的胶囊。输入一句话找相关灵感时，命中的胶囊成员临时以卡片浮到灵感流最前，退出后收回胶囊。 |
| 平台 | 本轮只做桌面端鼠标交互；触屏与手机手势不在范围内。 |

## 交互流程

### 建胶囊

1. 按住一张灵感卡拖动，卡片抬起并跟随指针。
2. 它和另一张卡的屏幕重叠面积达到自身 30% 并持续 120ms，目标卡轻微抬起，一张玻璃胶囊面板从目标卡位置展开。
3. 松手：两张卡收进新胶囊，胶囊出现在顶部资料架，名字取第一条成员的标题。
4. 在面板展开前或收起后松手：不创建胶囊，卡片回到原位。

### 打开与操作胶囊

1. 点胶囊面板任意位置，背后的灵感流模糊，居中出现胶囊浮层。
2. 浮层按 9 张/页展示全部成员，标题在顶部居中，点一下就能改名；拖动卡片排序，拖到面板左右边缘停一下翻页换位。
3. 点成员卡：浮层关闭，进入该灵感的编辑界面。
4. 把成员卡拖到浮层外的模糊背景：浮层保持打开，成员回到灵感流；胶囊不足两个成员时自动解散，浮层随之关闭。
5. 在浮层或关闭态胶囊上右键：「移出胶囊」（成员上）、「整体成稿」、「解散胶囊」。解散只解除归属。

## 验收场景

1. 灵感流里有 A、B 两张卡；拖动 A 与 B 重叠 ≥30% 并停留 120ms，玻璃胶囊轮廓展开；松手后生成胶囊，A、B 不再作为独立卡片出现，胶囊显示两张迷你卡与七个空位。
2. 拖动 A 靠近 B 但只停留 50ms 就移开，胶囊轮廓收起，松手不建胶囊。
3. 点胶囊里任意位置（含迷你卡）进入浮层；浮层顶部标题居中、可直接改名；按 Esc 关掉浮层后名字已经存下来。
4. 胶囊有 13 个成员：关闭态固定显示 9 张迷你卡，不显示条数；浮层第一页 9 张、第二页 4 张，只有左右两个翻页钮，第二页的「下一页」禁用。
5. 在浮层把第 1 张卡拖到第 4 张卡位置，顺序保存；关闭再打开顺序不变。
6. 在浮层把成员卡拖到模糊背景，浮层不关闭，成员回到灵感流。
7. 胶囊只有 A、B；在浮层右键 A 选「移出胶囊」，胶囊自动解散，浮层关闭，B 仍在灵感流里，无确认弹窗。
8. 胶囊只有 A、B；删除 A，胶囊自动解散，B 仍在灵感流里。
9. 把 A 从胶囊甲拖入胶囊乙；甲若只剩一个成员则自动解散，A 只出现在乙中。
10. 按标签筛选：只显示含命中成员的胶囊，命中的格子按顺序填进九宫格；清除筛选后恢复全量。

## 后果

- 胶囊从「叠加标记」变成真正的容器，卡片渲染、命中测试与拖拽状态都要重写；这是本次改动的主要成本。
- 成员灵感不再单独出现在灵感流里，页面更干净，但用户必须通过胶囊才能看到被收起的成员。浮层提供了完整入口。
- 胶囊不再需要画布坐标：散落模式撤销后，`pos` 一并下线（见 0003）。
- 自动解散降低整理成本，但删除成员比过去更「激进」；撤销仍可恢复胶囊与成员关系。
- 数据兼容：如果历史数据存在一个灵感属于多个胶囊，读取时保留第一个胶囊的归属，其余去掉重复成员并按新规则处理。

## 代码影响

- `client/capsule.jsx`：`CapsuleCard`（九宫格）、`CapsuleCell`（把真卡按比例塞进格子）、`CapsulePreview`、`CapsuleView`（浮层）、右键菜单。
- `client/canvas.jsx`：灵感流只渲染不在胶囊里的灵感；胶囊作为顶部资料架；拖拽建胶囊、拖入胶囊、成员拖出。
- `client/styles.css`：轻磨砂胶囊、九宫格与空位、拖拽预览、居中模糊浮层、分页钮、拖出提示。
- `src/ops.js` / `src/seed.js`：唯一归属、最少两个成员与自动解散、旧数据迁移。
