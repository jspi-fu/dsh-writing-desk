# 图文创作台 · Logo

**墨黑方块上一页翻动的稿纸，右上一点蓝。** 由用户亲手制作并矢量化（vectorizer.ai），为本项目唯一正式 Logo。

## 文件

| 文件 | 说明 |
| --- | --- |
| `logo.svg` | 矢量母版（1254×1254 视窗，127 条路径，透明底） |
| `logo.png` | 光栅母版（1254×1254 RGBA，透明底） |
| `icon.svg` | 图标版：同一画面，viewBox 收紧为方块 89% 填充 |
| `icon-{16,32,48,64,128,256,512,1024}.png` | 各尺寸图标（由 `logo.png` 裁切降采样，方块约占 89%） |
| `preview.html` | 浏览器打开，一览效果 |

## 使用规则

- 扩展 / 应用图标用 `icon-*.png`（已装入 `extension/packages/extension/assets/`，manifest 无需改动）。
- 大图展示用 `logo.svg` / `logo.png`；需要收紧留白时用 `icon.svg`。
- 不要改动构图与配色；不要给方块外加投影或描边。

## 溯源（provenance）

- 原作：用户手绘（含蓝色光点，为作者有意保留的设计元素）。
- 矢量化：vectorizer.ai，扁平分色路径，无渐变/滤镜定义。
- 图标裁切：以不透明区域 bbox `(279,273)–(972,958)` 居中取 776×776 视窗（`viewBox="238 228 776 776"`），方块约占画面 89%。
