# 图文创作台 · 正式 Logo（用户原作矢量版）

## 概念

**墨黑方块里一页翻动的纸。** 这个符号由用户亲手绘制：深色圆角方块上一页被风掀起的稿纸，纸面带着极淡的蓝紫粉虹彩印刷色。没有文字，只有「纸」与「编辑部」的意象——正对「书桌上的编辑部」的产品世界。

- **色彩**：保留原作的虹彩渐变——纸面从暖白（左下）过渡到雾蓝（右上），右侧翻卷面转入阴影；方块本身是近黑的深灰渐变。
- **去掉了蓝色发光点**：原图右上角的蓝色光点在小尺寸下过于抢眼、也偏「科技感」，与纸墨气质冲突，已移除。
- **单色版**：另提供墨黑剪影版，用于需要纯色的场景（印刷、徽章、单色环境）。

## 文件

| 文件 | 用途 |
| --- | --- |
| `icon-color.svg` | 彩色图标（方块 + 纸），矢量，推荐任意尺寸 |
| `icon-mono.svg` | 单色图标（墨黑方块 + 白纸） |
| `symbol-color.svg` | 只保留纸页的彩色符号（透明底，适合深色背景） |
| `symbol-ink.svg` | 纸页墨黑剪影（透明底，适合浅色背景） |
| `icon-{16,32,48,64,128,256,512,1024}.png` | 彩色图标光栅（透明底，方块占画面约 89%） |
| `logo-{512,1024}.png` | 原构图彩色光栅（留白更足，用于 README / 落地页） |
| `preview.html` | 浏览器打开，一览全套与尺寸测试 |

## 使用规则

1. 扩展 / 应用图标用 `icon-*.png`（已装入 `extension/packages/extension/assets/`）。
2. 深色背景上的大图用 `symbol-color.svg`；浅色背景用 `symbol-ink.svg`。
3. 需要单色印刷时用 `icon-mono.svg` / `symbol-ink.svg`。
4. **不要**把 `symbol-color.svg` 放在同样浅的纸色背景上（纸页是亮色，会糊边）。
5. **不要**再补回蓝点或额外加光效；不要把方块改成纯黑或浅灰。

## 溯源（provenance）

- 形状：由用户提供的 1254×1254 PNG 原作，经 vtracer 矢量追踪（spline，512×512 坐标系）得到轮廓；蓝色光点区域用周边墨色修补后去除。
- 色彩：SVG 渐变取样自原作（纸面 `#f8eff4 → #f0ecf7 → #e7ecfa → #dde4f4`，阴影叠加至 `#14161d`；方块 `#202023 → #18181b → #111113`）。
- 光栅：由去点后的 1254px RGBA 母版高质量降采样（Lanczos），透明底；光栅母版即 `logo-1024.png`。
- 追踪与导出脚本为一次性工作，交付后已清理。
